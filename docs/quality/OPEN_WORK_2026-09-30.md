## 1. Hemen sıradaki adımlar (önerilen sıra)

1. **Yerel kurulumu bitir.**
   - 8081 portunu kontrol et: `lsof -nP -iTCP:8081 -sTCP:LISTEN`.
   - `npm run dev:mobile` ile Metro'yu başlat.
   - Simulator'da Blumi'yi aç.
   - Sonra telefonda development build'i kur: `npm --workspace @blumi/mobile run ios -- --device`. Bu kurulum TestFlight'taki Blumi'nin yerine geçer; TestFlight'tan istediğin zaman geri yüklenebilir.
2. **Bugünkü düzeltmeleri telefonda test et** (bkz. §2.1).
3. **Testler geçerse `develop` → `main` birleştirmesi yap.** Production build 13 ve sunucu buradan beslenir. `main`'e gelen server değişiklikleri Railway'de otomatik deploy oluyor.
4. **UX hızlı kazanımlarına başla** (§3.2). Senin "başla" demeni bekliyor.
5. **Belgelerdeki yanlış bilgileri düzelt** (§10). Birkaç belge, bitmiş işleri hâlâ yapılacak gibi gösteriyor.
