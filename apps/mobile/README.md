# Blumi SDK 57

Standalone Expo SDK 57 mobile app extracted from the Blumi workspace.

## Setup

```bash
npm install
```

## Run

```bash
npm run ios
```

For Metro only:

```bash
npm run start
```

## Notes

- Expo SDK: `57`
- React Native: `0.86`
- Local iOS bundle id: `com.blumi.mobile`
- Home Studio QA module routing is handled through [metro.config.js](./metro.config.js)
